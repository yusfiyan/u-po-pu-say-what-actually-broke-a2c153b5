# Say What Actually Broke

One line of software error copy, at most 200 characters, that tells the user the brutal truth about what went wrong — and makes them laugh on the way.

> The server ran out of disk space mid-save, so your file is nowhere and the green checkmark lied to you. Try again — we just cleared 4 GB of logs nobody had read since 2019.

Run: `node main.ts` (writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR`)
